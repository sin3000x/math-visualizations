# 基、坐标、行向量

独立第三集。目前实现两幕，沿用第一集水果袋的造型与实数净重量语义。

运行：`npm ci`、`npm run dev`。检查：`npm run lint`、`npm test`、`npm run build`、`npm run video:check`。

## 第一幕：两个袋子生成整个空间

1. 水果袋线性空间：包含正重量、分数、退货与零袋，袋子图案沿用第一集。
2. 选出 e1（1 斤苹果、0 斤香蕉）和 e2（0 斤苹果、1 斤香蕉）。
3. 直接展示任意袋子的线性组合，无动画，不显示 V 和椭圆。系数为任意实数 a、b：水果袋（a 斤苹果、b 斤香蕉）= a × 苹果单位袋 + b × 香蕉单位袋。负数水果用虚线轮廓，零斤项隐藏，袋子始终为实线。
4. 按右方向键，两个基袋移动到方括号内组成一行，系数 a、b 移到右侧组成一列，表示同一个线性组合。行向量以 V 中的基袋为条目，列向量是实数坐标，乘积仍是 V 中的袋子。动画完成后停住，左方向键可还原展开式。

方向键逐步推进，数字键 1–4 跳转当前幕的步骤。画布外提供场景切换与全屏录制，Escape 退出录制。固定 1440×810 设计、1920×1080 输出。画布无标题、说明与导航。

## 实现边界

播放器来自 scene-project 模板；FruitBag 与样式放在一起，图标复制自稳定项目。数学计算放在 lib/math/bags.ts，数字格式不固定四舍五入到一位小数。两集旧项目未迁移。后续独立教学目标以新增 Scene 扩展，不提前引入通用线性代数框架。

`npm run check:layout` 检查普通桌面、窄屏和 1080p 的全部步骤、对象边界与键盘导航，截图输出至 `exports/qa-layout/`。

## 第二幕：用基袋测出单价

依次展示收银台、一张静态线性性质图（上排加法 24 = 13 + 11，下排数乘 26 = 2 × 13）、屏幕上的两个问号单价、放入苹果单位袋、得到 5 元、苹果单价填入 5 并移除结果标签、换入香蕉单位袋、得到 3 元、香蕉单价填入 3 并移除结果标签。数字键 1–9 跳步；放袋动画结束后停住等待下一步。价格是重量的线性函数，不含起步费或折扣。

所有收银台从一开始均不显示小票。静态图与测价画面共用托盘和袋底坐标；单价位于放大的屏幕内。测价画面不显示基袋名称或函数公式。屏幕外文字统一浅白色，屏幕内文字使用深色，水果保持原有颜色。
