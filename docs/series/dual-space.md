# 对偶空间系列

用同一个“水果袋 / 收银台”世界讲有限维线性代数里的对偶：水果袋是向量（苹果、香蕉两个实数分量，单位斤，负数为退货），收银台是线性泛函（按单价结算）。每集是 `projects/` 下的独立子工程，项目名是稳定 id，集数只在本文和各项目 README 中记录。

## 各集

| 集 | 项目 | 标题 | 核心关系 |
| --- | --- | --- | --- |
| 1 | [`dual-space`](../../projects/dual-space/) | 对偶空间 · 水果收银台 | 所有水果袋构成线性空间，所有收银台构成它的对偶空间 |
| 2 | [`double-dual`](../../projects/double-dual/) | 对偶的对偶 | 一袋固定水果就是对收银台的测量，`v ↦ (f ↦ f(v))`；有限维时 V ≅ V** |
| 3 | [`basis-coordinates`](../../projects/basis-coordinates/) | 基、坐标、行向量 | 基袋给出坐标；收银台在基上的报价组成行向量，换基价格不变 |
| 4 | [`dual-basis`](../../projects/dual-basis/) | 对偶基 | fᵢ(eⱼ)=δᵢⱼ：对偶基读出坐标，线性无关并张成 V* |
| 5 | [`linear-map`](../../projects/linear-map/) | 线性映射与矩阵 | 榨汁机把水果袋映到果汁托盘，基袋的像组成矩阵的列；收银台是新基为 1 的特例 |

各集的分镜、数学约定和验收命令写在对应项目的 README。

## 共用约定

- **对象**：水果袋 `FruitBag`、收银台 `CheckoutIcon`、单价屏 `UnitPrices`、放袋动画 `CheckoutPlacement`、榨汁机 `JuicerIcon` 来自 `@math-visualizations/scene-kit`。第 1、2 集保留各自的旧版收银台（带小票），以免改变已发布成片；新集一律用 scene-kit 版本。
- **配色**：苹果基袋 e₁ 及其对偶 f₁ 用苹果红，香蕉基袋 e₂ 及其对偶 f₂ 用香蕉黄；一般水果袋用青色 `--vector-color`，一般泛函用紫色 `--functional-color`。第 5 集为避开果汁三色，一般水果袋改用中性浅灰（见其 README）。
- **常用数值**：示例袋 (2, 1) 配单价 (5, 6) 得 16（第 2 集）；单价 苹果 5、香蕉 3（第 3、5 集）。后续集沿用时保持一致。
- **范围**：代数对偶、有限维、实数系数；涉及无限维时只点明边界，不展开。

## 后续计划

1. 转置：线性映射如何反向作用在收银台上（`Tᵀ: W* → V*`），可直接接第 5 集的榨汁机与收银台。
2. 协变与逆变：换基时向量坐标与对偶坐标为什么反着变，接第 3 集的换基。

新增一集：`node scripts/create-project.mjs <项目名>` 创建后，在上表登记，并在项目 README 第一行写明“对偶空间系列第 N 集”。
