# 对偶的对偶

独立的第二集开场原型。水果袋、收银台及样式复制自 dual-space，在本项目内维护，不跨项目导入源码。

```sh
npm ci
npm run dev -- --port 4174
```

方向右键逐步展示：V 与 V* 及其中的水果袋、收银台同时出现 → 下方水果袋落在收银台托盘上，得到价格 16 → V** 中出现问号，下方托盘与价格也同步变成问号 → 上方与托盘的问号同步变成同一袋水果，价格同步恢复为 16。左键返回，数字键 1–4 跳转，PageDown / PageUp 同样可用。点击画布外“全屏录制”，Escape 退出。动画结束后等待按键，不自动推进。

画面没有标题、说明和导航栏；固定 16:9，按 1920×1080 验收。包含两个 Scene：第一幕从回顾到悬念，再揭示同一袋水果可以定义对收银台的测量；第二幕通过超市购物与物价调查对比固定收银台和固定水果袋。

数学约定：沿用实数水果重量空间，袋子示例为 (2, 1)，收银台是权重 (5, 6) 的线性泛函，读数由点积计算为 16。图中仅展示各空间中的一个代表元素，椭圆表示集合，不表示有界性或距离。双对偶是对线性泛函再做线性测量的空间，最后用水果袋表示其对应的评价泛函：把任意收银台作用于这袋固定水果所得到的价格，作为对该收银台的测量。水果袋与评价泛函有自然对应，但属于不同空间；画面复用图标表达对应，并不宣称它们是同一个类型的对象。展示为正数的购买例子不限制空间中的坐标必须非负。

验证：`npm run lint`、`npm run build`、`npm test`。遵循根目录 AGENTS.md。

新增超市场景共 6 步，第一幕结束后按右键进入，数字键 1–6 可跳转：

1. 购物者与一个固定收银台。
2. 一竖排三袋不同重量的水果。
3. 三袋水果依次进入同一个收银台，得到 11、16、17 元。
4. 调查员与固定的一袋水果（2 斤苹果、1 斤香蕉）。
5. 一竖排三个不同的收银台。
6. 同一袋水果的测量动画依次进入三个收银台，得到 16、13、19 元；源袋保持可见，移动图像表示同一袋水果的三次测量。

两组测量均一次按键触发。第一部分每袋动画历时 1.25 秒，完全消失后再等待 0.1 秒启动下一袋，起始间隔 1.35 秒，整组约 4.3 秒结束。第二部分起始间隔 0.4 秒，各袋到达后保留在对应托盘上，整组约 2.4 秒结束。到达后输出价格，结束后停住。可用左键回退并重新播放，不自动推进步骤。单价保留在代码中线性计算；画面不显示单价、店名或身份文字。角色使用统一日漫 Q 版 PNG，通过制服、红袖箍与记录板辨认调查员，价格仅用于教学。
