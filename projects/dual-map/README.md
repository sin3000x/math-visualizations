# 对偶映射

[对偶空间系列](../../docs/series/dual-space.md)第 6 集。

在根目录运行 `npm run dev -w dual-map`。方向键逐步推进，数字键跳步；外部工具栏进入全屏录制，Escape 退出。画布固定 16:9，底部 16% 留给字幕。

## 数学模型与口播约定

沿用第 5 集：水果袋空间 V（苹果、香蕉，单位斤），果汁空间 W（A、B、C 三种果汁，读数单位为份，1 份 = 100 mL），榨汁机 T: V → W 每斤苹果榨出 (2,1,1)、每斤香蕉榨出 (1,2,1)。三杯从左到右为 A、B、C，颜色为青、蓝、紫；一般水果袋用中性浅灰，基袋用苹果红、香蕉黄。

- **水果收银台** f ∈ V*：scene-kit 的 `CheckoutIcon` + `UnitPrices`，灰色机身、青色屏，袋子放在右侧托板上。开场与反例用 5、3 元/斤（第 3、5 集的单价）。
- **果汁收银台** φ ∈ W*：本集新设计（`components/Checkouts.tsx`），与水果收银台区分——暖棕色宽矮柜台、米色竖屏显示三行“杯子 + 元/份”、托盘放在右侧沥水格栅上，托盘读数落在柜台正面。单价 φ = (1, 2, 1) 元/份。
- **对偶映射** T*: W* → V*，T*φ = φ∘T：把一袋水果先榨成汁，再给果汁结账。先榨汁再结账是线性的，所以它是一台合格的水果收银台。T*φ 的单价是两只基袋榨汁后的价格：φ(2,1,1) = 2+2+1 = 5、φ(1,2,1) = 1+4+1 = 6，正好是第 2 集的 (5, 6)；检验袋 (2,1) 先榨汁再结账与按 5、6 元/斤直接结账都是 16 元。
- **反例**：托盘 (2,2,1) 不是任何一袋榨出来的（像空间里第三项是前两项之和的三分之一）。口播的要点是榨汁机只会往前走，不能把果汁逆转成水果，所以水果的定价给不出果汁的定价；“不在像里”的托盘是最直观的例子。
- 本集不出现矩阵；T* 的矩阵是 T 的转置，留给下一集。复合的反序 (S∘T)* = T*∘S* 也不在画面里出现，只在测试里验证。

紫色表示对偶一侧（V*、W*、T*、φ、T*φ、T* 箭头，以及“这一整套是一台水果收银台”的框），与 C 果汁同色但不在同一对象上出现。

## 分镜

口播文案在备忘录“对偶空间 - 06 对偶映射”。全集共用一个“方块”构图（`scenes/layout.ts` 的 `BOARD`）：上行 袋 → 榨汁机 → 托盘（V → W），下行左边水果收银台、右边果汁收银台，各自正对上方的袋子与托盘。每一步的方块状态集中在 `scenes/steps.ts`，下一幕第 1 步是上一幕最后一步的 `still()`，衔接自动一致。

1. JuiceCheckoutScene（4 步）：水果收银台（5、3）上落下一袋 (2,1)，得 13 元；右边出现果汁收银台（1、2、1 元/份）；一托盘 (5,4,3) 落上格栅；得 16 元。
2. NoPushforwardScene（5 步）：复现上一幕；袋子、托盘与结果淡出，果汁单价变成问号，榨汁机出现在上方（箭头只往右），停住给观众思考；右上方来了一托盘 (2,2,1)；珊瑚红虚线从托盘绕过榨汁机下方往回，指向左上方的问号；虚线上打叉——榨汁机不能逆转。
3. PullbackScene（7 步）：复现上一幕；虚线、问号、叉与托盘淡出，果汁单价变成 1、2、1，水果单价变成问号；左上方出现一袋 (2,1)；榨汁得 (5,4,3)；托盘放上果汁收银台，得 16 元；同一袋放上水果收银台，16 元从果汁收银台复制过来——这就是这袋水果的价格；紫色虚线框先框住榨汁机到结果这一整套，再移到水果收银台上——这一整套就是一台合格的水果收银台。
4. DualMapScene（5 步）：复现上一幕；框、袋子与结果淡出，下行出现从果汁收银台指向水果收银台的紫色箭头 T*（价格翻译 = 对偶映射）；写出 V、W、T 与 V*、W*；果汁收银台标 φ，水果收银台标 T*φ；中间写出 T*φ = φ∘T，这是全集唯一的公式。
5. PulledPricesScene（8 步）：复现上一幕；名字淡出，苹果基袋出现；榨出 (2,1,1)；放上果汁收银台，逐杯 2+2+1（按三种果汁着色）合计 5 元；5 飞进水果收银台屏幕的苹果单价；香蕉基袋出现并榨出 (1,2,1)；逐杯 1+4+1 合计 6 元；6 飞进香蕉单价。
6. TwoWaysScene（4 步）：复现上一幕；香蕉袋、托盘与结果淡出，一袋 (2,1) 出现并榨出 (5,4,3)；托盘放上果汁收银台得 16 元；同一袋放上水果收银台，按 5、6 元/斤直接结账也得 16 元，两个 16 并排停住。
7. ContravariantScene（4 步）：复现上一幕；方块淡出，上行出现 V → W 与 T；两条竖直的紫色箭头把 V、W 分别送到 V*、W*（对偶操作把空间变成收银台空间）；T 箭头的复制品原地转半圈落到下行，成为 W* → V* 的 T*（对偶操作把映射的方向反过来）。口播在这张图上说出“反变（逆变）函子”。

## 实现

- 果汁托盘 `JuiceTray` 已提升到 `@math-visualizations/scene-kit/JuiceTray`（第 5、6 集共用），说明见 [公共组件说明](../../packages/scene-kit/juice-tray.md)；榨汁机用 `JuicerIcon`。
- 袋子与托盘放上收银台统一用 scene-kit 的 `CheckoutPlacement`（`source` 指向上行的袋子或托盘）；结算结果和单价数字的复制飞行用 `lib/fly.ts`，按实际 DOM 边界换算，飞行途中保持来源颜色，落定后换成屏幕上的深色字。
- 数学值在 `lib/math/prices.ts`，`tests/prices.test.ts` 验证 T*φ = (5,6)、(T*φ)(v) = φ(Tv)、反例托盘不在像中以及 (S∘T)* = T*∘S*。

## 检查

`npm run check`；`npm run check:layout -w dual-map`（逐步核对托盘读数、水果收银台屏幕单价与两台收银台的结算结果）；`npm run video:check -w dual-map`。输出写入 `exports/`（软链接到 iCloud 的 bilibili/math-visualizations/dual-map/exports）。
