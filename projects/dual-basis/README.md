# 对偶基

对偶空间系列的独立项目。沿用 basis-coordinates 的水果袋和 double-dual 的收银台图形，使用共享 ScenePlayer 与 KaTeX。

在仓库根目录执行 `npm run dev -w dual-basis`。方向键逐步前后切换，数字键 1–9 直达当前 Scene 的已有步骤，点击“全屏录制”进入录屏模式，Escape 退出。

## 开场：基与对偶基

同一幕六步，所有动画完成后停住等待按键：

1. 水果袋空间 V：e₁ 是 1 斤苹果，e₂ 是 1 斤香蕉。
2. 对偶空间 V*：同时展示 f₁ 和 f₂，苹果、香蕉单价分别为 (1, 0) 和 (0, 1)。
3. e₁ 放到 f₁ 的托盘上结算，读数为 1，停在托盘上。
4. e₂ 放到 f₁ 的托盘上结算，读数为 0，停在托盘上。
5. e₁ 放到 f₂ 的托盘上结算，读数为 0，停在托盘上。
6. e₂ 放到 f₂ 的托盘上结算，读数为 1，停在托盘上；四个关系完整保留。

数学模型：V 是以苹果、香蕉数量为坐标的二维实向量空间，允许实数坐标。收银台表示线性泛函 f₁(x,y)=x、f₂(x,y)=y；金额读数采用固定单位下的实数值。因此 fᵢ(eⱼ)=δᵢⱼ，f₁、f₂ 是这组基对应的对偶基。

画布底部 16% 留作后期字幕安全区（1080p 下约 173px），图形与四个取值关系均位于安全区上方。

## 读出水果斤数

`CoordinateReadingScene` 接在开场之后，共六步。前三步：先展示含 3 斤苹果、2 斤香蕉的水果袋 v；再把袋子放到 f₁ 上，得到 3；最后把同样的袋子放到 f₂ 上，得到 2。两次放袋均使用共享 CheckoutPlacement，结果与袋子保留在各自收银台，方便对照。f₁(v)=3、f₂(v)=2 表示分别读取两个水果坐标。第四步将同一袋水果写成 3 倍苹果单位袋加 2 倍香蕉单位袋。系数 3、2 直接复用两个收银台的读数元素，从结算位置移动到对应基袋前；保留数值和颜色，不再显示坐标列和提取箭头。第五步用 1 秒补间把上方展开式对应到下方的 v = 3e₁ + 2e₂，保留数字系数。第六步再用 1 秒将下方 3、2 分别变成 f₁(v)、f₂(v)，得到 v = f₁(v)e₁ + f₂(v)e₂；其他符号保持原位，所有 v 使用青色，f₁/e₁ 使用苹果红，f₂/e₂ 使用香蕉黄。

## 对偶基线性无关

`CheckoutIndependenceScene` 共八步：标题；以三个收银台表示零线性组合；三袋一斤苹果在托盘上同时出现；将三个完整的结算项（系数、收银台、袋子和标签）及运算符复制并以轮廓补间变形到下方，组成 x + 0 = 0；记录 x = 0；三个托盘上的苹果同时换成一斤香蕉；下方同样得到 0 + y = 0；记录 y = 0，得到线性无关。上方收银台等式始终保留，右侧零收银台的两种水果单价均为零。

## 对象配色

本项目中，苹果基袋 e₁ 与对偶基 f₁ 统一使用苹果红，香蕉基袋 e₂ 与对偶基 f₂ 统一使用香蕉黄。一般水果袋 v 使用青色（`--vector-color`），一般泛函 f 使用紫色（`--functional-color`）。基袋须显式指定 FruitBag 的 apple / banana tone；未指定时使用一般向量的青色。袋内水果仍保持各自颜色。

轮廓补间实现与资产重生成方法见 [lib/animation/README.md](lib/animation/README.md)。

## 对偶基张成整个对偶空间

`CheckoutSpanningScene` 接在线性无关之后，共九步，标题为“f₁, f₂ 可以张成整个对偶空间”：

1. 直接用 3、2 和两个基袋表示具体水果袋的分解，不展示 a、b 或下方公式。
2. 先用共享 CheckoutPlacement 将三袋缩小并移到托盘位置（0.8 秒）；袋子到位后，三个空屏收银台 f 再出现。
3. 保留这三个 f 结算图标，将 3、2 分别用 1 秒轮廓补间直接变成完整的 f₁(v)、f₂(v) 结算图标（收银台、输入袋及标签一起生成）。不再从左式复制或飞入水果袋，也不以 f(e₁)、f(e₂) 文字代替已有图标。
4. 只交换因子的顺序，沿上、下路径错开；f₁、f₂ 托盘上的输入袋保持不变。
5. 下一次按键，两个托盘上的同一输入袋分别沿弧线移动到括号外，1.1 秒后在同一位置重合，留下一个共同输入袋；全过程保持每袋 3 斤苹果、2 斤香蕉，不做数量相加。
6. 一次按键触发 8 次整袋滚动：旧水果袋向上滚出，新水果袋从下方滚入，每次滚动 0.25 秒、到位后停留 0.2 秒；左右两个输入袋完全同步，两个基袋结算项不变。总时长 3.8 秒，最后一袋保持到下次按键。
7. 两端输入袋连同括号在 0.8 秒内同步淡出，保持最后一袋的内容直至消失；保留任意 f 与右边两个基袋结算项及 f₁、f₂ 收银台，图标居中排列，下方同步显出逐项对齐、颜色对应的 `f = f(e₁) f₁ + f(e₂) f₂` 标签。

8. 标题淡出，图标与分解式整体上移，在下方展示 f 在对偶基 (f₁, f₂) 下的列坐标。
9. 右下方显出“回顾”子区域：用行向量 [f(e₁), f(e₂)] 乘以 v 在 (e₁, e₂) 下的坐标列，表示 f 在 V 上的作用。

推导对任意 v 成立；换袋仅用于直观演示，有限个例子本身并非张成性的证明。水果坐标沿用整个项目的实向量空间模型。

`node scripts/check-spanning.mjs` 额外验证整袋连续滚动、200ms 停留、8 次变化、左右输入同步和线性恒等式（包括零、负数与分数）。
