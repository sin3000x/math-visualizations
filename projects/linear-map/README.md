# 线性映射与矩阵

在根目录运行 `npm run dev -w linear-map`。方向键逐步推进，数字键跳步；外部工具栏进入全屏录制，Escape 退出。画布固定 16:9，底部 16% 留给字幕。

## 数学模型与口播约定

水果袋空间 V 沿用苹果、香蕉两种分量，单位为斤。输入有序基 E=(e₁,e₂) 是一斤苹果、一斤香蕉。
果汁空间 W 有A 果汁、B 果汁、C 果汁三个分量。每个读数单位为 100 mL；输出有序基 U=(u₁,u₂,u₃) 是这三类果汁各一个产量单位。三种杯子从左到右始终为 A、B、C，依次对应矩阵的第一、第二、第三行，颜色始终为青、蓝、紫，苹果和香蕉基列始终为红、黄。

这是固定工艺、固定产量的理想模型；A、B、C 表示三种固定输出类别，忽略口味组成、损耗变化、批次和容量限制，不是真实榨汁配方。每斤苹果的三项产量为 (2,1,1)，每斤香蕉为 (1,2,1)。

开场口播先交代：袋子和杯子表示可加减的净数量；正数是增加，负数是扣除，零是没有净变化。实际存量非负，只是实向量空间的一部分。线性关系对任意实系数成立；画面用非负例子建立直觉。

## 分镜

1. JuiceMapScene：V 中的多种水果袋；W 中的多种果汁组合；固定同一袋 (2,1)，逐步展示 T、S、R 三台榨汁机，分别得到 (5,4,3)、(3,5,2)、(4,2,6)。S 的两列取 (1,2,0)、(1,1,2)，R 的两列取 (2,0,2)、(0,2,2)。W 中最初的例子仅表示空间元素，不声称均为 T 的输出。后续各幕固定使用 T。开场说明杯子顺序和单位，基向量在 BasisImagesScene 引入。
2. LinearityScene：分别投入两袋；两袋合并且产量相加；单个基袋；输入和产量同时加倍。口播将例子推广为 T(av+bw)=aT(v)+bT(w)。
3. BasisImagesScene：苹果基袋；其输出及坐标；香蕉基袋；其输出及坐标。这里的像属于 W，不是单个实数。
4. MatrixColumnsScene：第一列；第二列；两列移动并组成矩阵；注明固定有序基 E、U 下的矩阵。三行对应三种果汁，两列对应两种水果。矩阵依赖基的选择。
5. MatrixActionScene：具体输入；矩阵乘坐标列；按列做线性组合并得到果汁；推广为 [T(v)]_U=A[v]_E。矩阵记录映射在所选基下的作用。

W 是三维空间，但这个映射的输出只落在其中一个二维子空间：第三项等于前两项之和的三分之一。无需把“输出空间三维”误说成“任何三杯都可由水果袋产生”。本期画面不额外展开秩与像空间。

## 检查

`npm run check`；`npm run check:layout -w linear-map`；`npm run video:check -w linear-map`。录制入口和停留时间位于 scripts/video；输出全部写入被 Git 忽略的 exports。

榨汁机使用公共组件 `@math-visualizations/scene-kit/JuicerIcon`，用法见 [公共组件说明](../../packages/scene-kit/juicer-icon.md)。
