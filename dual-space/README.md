```bash
npm run dev
```

第一节分六步揭示袋子与收银台；第二节分八步验证线性空间公理。方向键或 `PageUp` / `PageDown` 可跨步骤、跨 Scene 导航，数字键跳转当前 Scene 内步骤，`Escape` 退出录制模式。
