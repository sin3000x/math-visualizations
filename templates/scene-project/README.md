# 数学可视化子项目

从 dual-space 提取的独立 React + TypeScript + Vite 模板。先运行两段示例，再替换教学内容。

```sh
npm ci
npm run dev
```

需要 Node.js >= 22.13。端口以 Vite 输出为准；可用 `npm run dev -- --port 4180` 指定端口。

## 添加自己的内容

1. 在 `scenes/` 编写组件，接收 `SceneProps` 的 `step`，从零开始逐层展示内容。
2. 在 `scenes/registry.ts` 设置项目名称、概念 ID，并登记每个 Scene 的稳定 ID、顺序、名称、目标、组件及 `stepCount`。导航自动生成，不在 App 中增加分支或步骤数组。
3. 替换 `index.html` 的网页标题及描述，删除两个示例组件及对应注册项。
4. 数学计算放在 `lib/math/`，坐标变换放在 `lib/geometry/`，按需要创建目录。

`components/ScenePlayer.tsx` 管理 Scene 和步骤状态、键盘和全屏；`app/App.tsx` 只选择概念。每个 Scene 切换时重新挂载，步骤变化时保留当前 Scene 的局部状态。需要重置某段动画时，在该动画组件上用 `key={step}`，不要给整个播放器加 key。

注册表检查 ID 唯一、同概念顺序唯一及步骤数为 1–9；查询按顺序排序。`route` 是 Scene 元数据；本模板在 `/` 内切换状态，没有安装路由器，不支持通过 Scene URL 直接跳转。

## 布局与导航

普通模式保留纸张背景、Scene 标签和“全屏录制”；Scene 名称只在标签中出现一次。画布纯黑，内部用 **1440×810** 坐标设计，由 `.scene-design` 一次等比缩放到 16:9 外框。设计契约和验收视口为 **1920×1080**。

Scene 内容可用区域为 1344×714（外层 48px 留白），不为底部导航预留空间。Scene 内使用固定尺寸或相对父容器的尺寸，不用 `vw/vh` 重排内容；不要自行再缩放整个 Scene。窄屏只缩小画布，不改变构图。

普通模式的步骤导航位于画布外顶部工具栏。普通模式和录屏模式的页面底部及画布内均不显示导航栏、步骤按钮或页码。全屏录制隐藏外部工具栏和 Scene 标签，通过键盘导航；浏览器拒绝原生全屏时保留 CSS 录屏模式。按 Escape 退出。

- 右方向键 / PageDown：下一步，到末尾进入下一 Scene。
- 左方向键 / PageUp：上一步，到开头返回上一 Scene。
- 数字键 1–9：跳转当前 Scene 内步骤。
- 输入框、选择框及可编辑内容保留原生键盘行为。

公式统一用 `MathFormula`；SVG 标签用 `SvgFormula`。公式字体与横向排版由全局样式负责。示例中的两条线段共用比例尺，长度分别为 300 和 600，对应数值 2 和 4。

## 验收

```sh
npm run lint
npm run build
npm test
git diff --check
```

同时检查普通桌面、窄屏、1920×1080 全屏录制下的所有 Scene / 步骤：KaTeX 无错误、控制台无运行时错误、录屏无滚动、内容在画布内、页面底部和画布内无导航、键盘跨 Scene 往返及 Escape 正常。新增交互另按根目录 AGENTS.md 验证数学关系与边界状态。

本子项目保有自己的依赖、锁文件和源码；模板后续改动不会自动修改本项目。根目录 AGENTS.md 是统一工程规范。
